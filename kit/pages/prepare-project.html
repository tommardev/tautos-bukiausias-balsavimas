Prepare project rules

After the harness exists, the agent writes a lean AGENTS.md spine (including when-to-load Pointers), on-demand helpers, thin shims only for tools that cannot read AGENTS.md, and a gap-fill of this project's human README.md (creates it if missing). Skip this step when joining a clone that is already prepared — those files are the team’s committed workflow. It does not invent a stack. Golden defaults apply only where this project is silent; the project's own standards win when they are more correct or specific — including an existing README structure that already covers the usual jobs.

What you do

Your checklist

Joining a prepared repo? Stop. Use step 1 · Joining (or AI_CODING_README.md). Do not re-run this step.

  1. Port the kit if it is not already in the target repo — paste the prompt from the GitHub README into an agent opened on that local project.
  2. Finish step 1 (or let the agent do both steps from the bootstrap prompt).
  3. Review what the agent writes: root AGENTS.md (with Pointers to helpers), host README.md (created or gap-filled, not reshaped if it already covers the jobs), AI_CODING_README.md, AI_CODING_LEARN.md, helpers under docs/agents/, and thin shims only where a tool cannot read AGENTS.md (CLAUDE.md, Copilot). It should not write globbed project Cursor rules, and should not commit unless you ask.
  4. When you are done, delete the fetched kit/ folder from the host (recommended). Keep the harness files, AI_CODING_README.md, AI_CODING_LEARN.md, AGENTS.md, and the project README.md. Do not delete kit/ in this GitHub repo.

Tools stanza (portable)

Even when Cursor native rules exist, AGENTS.md gets a short Tools block so other clients follow the same defaults:

  • Library/framework docs: Context7 MCP, not client web search or training memory.
  • Package versions and security: Sonatype MCP before adding or pinning dependencies.
  • GitHub: gh CLI only (no GitHub MCP).

How rules are chosen

Agents must not invent a second style guide, and must not average conflicts. Named golden defaults (WCAG 2.2 AA, design tokens, official language guides, OWASP, AGENTS.md spec) apply only where this project is silent. Details live in golden-rules.md.

Rank Wins when
User chat Always
This project's code, linters, tokens, existing agent files Taste, architecture, naming, formatting — including when stricter or more specific than a common default
Golden default The project is silent and the rule applies to this stack
Safety / accessibility floor Never copy a dangerous or inaccessible habit as the canonical way
