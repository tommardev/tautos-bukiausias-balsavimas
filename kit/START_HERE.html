For coding agents

Operating contract. Execute it. Detail is in the skill files, not on this page.

  1. Classify first (host git root). Join if AGENTS.md, skills-lock.json, and AI_CODING_README.md exist — machine-local harness only; do not fetch kit/; do not rewrite team files.
  2. Kit root is the directory that contains this HTML file (first-time fetch only).
  3. If this workspace has no kit and the host is first-time, fetch kit/ from GitHub (README prompt) then continue.
  4. Read skills/prepare-project-for-agents/SKILL.md. Mandatory on first-time (and when kit is already on disk).
  5. Step 1 — harness first. Read and execute references/harness.md (Join section when already prepared). You run npx skills experimental_install --yes (GitHub sources in the lockfile). Surface /add-plugin only for plugins missing on this machine.
  6. Step 2 — project rules (first-time only). Then instruction-prompt.md and golden-rules.md.
  7. Host is the git toplevel. If the kit is a subfolder, write into the host.
  8. Do not invent conventions. Do not commit unless asked. Finish with templates/report.md (join section when joining). If you fetched this folder from GitHub in this run, ask before deleting it (recommended: yes).
